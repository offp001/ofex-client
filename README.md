## About ofex-client

**ofex-client** is a client that allows you to block servers—such as Foxnet—that attempt to ban you by scanning your client.

This client changes your KRX Version hash, name. and lets u join servers like foxnet etc.

### Key Features

* **Version Hash Modification:** Changes your KRX Version hash seamlessly
* **Identity Control:** Modifies your client name and parameters
* **Unrestricted Server Access:** Lets u join servers like foxnet etc. without being blocked by client scanning
